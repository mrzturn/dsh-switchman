> **Семейство switchman**, один автор, одна оркестрация: [opencode-switchman](https://github.com/mrzturn/opencode-switchman) (оригинал для OpenCode) · [zcode-switchman](https://github.com/mrzturn/zcode-switchman) (порт для ZCode) · **dsh-switchman** (этот репозиторий, для DeepSeek Harness).

![dsh-switchman — уровень воды в контексте управляет стрелочником, и тот переводит маршрут](docs/assets/hero.svg)

> Контекст под счётчиком. Задачи распределяются сами.

Плагин для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH). После установки ваша основная модель перестаёт всё делать сама и становится диспетчером: измеряет уровень воды, выбирает полосу, раздаёт задачи, проверяет работу. Четыре вещи:

**1. Контроль уровня воды в контексте.** Каждый ход замеряет фактическое потребление токенов сессии. Soft (по умолчанию 50k) советует делегировать, hard (90k) урезает бюджет чтения на ход и подталкивает к завершению, force (130k) делает бэкап сессии и передаёт её компакции — автоматически. Держите сессию открытой хоть весь день; ваш контекст не утонет в собственной истории. Каждый отправленный субагент несёт собственный hard cap и по его достижении выходит с резюме HANDOFF.

**2. Диспетчеризация по шести полосам.** economy / mechanical / main / hard / vision / review — шесть когнитивных полос. Выберите модели-кандидаты по каждой полосе на странице настроек, расставьте от сильнейшей (опциональная привязка к tier-ам S/A/B/C) и зафиксируйте reasoning effort для каждого маршрута — в выпадающем списке те уровни, которые каждая модель *реально* поддерживает, а не три универсальных. Таблица `[SWITCHMAN:POOLS]` уходит с каждым промптом, чтобы модель знала, кого вызывать; режим `enforce` наотрез отвергает модели вне пула. Маршруты, которые настройки DSH сессии не авторизовали для явного выбора субагента, помечаются ⚠ и в таблице пулов, и на странице настроек, отсылая вас к настройкам DSH (Subagents → model selection), чтобы авторизовать их — иначе агенты переходят к неявной диспетчеризации. Независимость ревью привязывается к модели **автора** кода (агента, создавшего diff), а не к модели основной сессии.

**3. Языковые предпочтения.** По одному выпадающему списку для ответов, комментариев в коде и создаваемых документов. Не задано? Спросят один раз, запомнят навсегда, и каждая следующая сессия будет этому следовать.

**4. Доктрина delegate-by-default.** Заменяет поставляемую в DSH консервативную политику команд («создавайте teammates только по прямой просьбе»): мелочёвка остаётся ручной работой (<200 прочитанных строк, <50 изменённых), настоящая работа по умолчанию делегируется; каждое изменение проверяется — больше 20 строк уходит тестировщику, больше 300 строк или ядро логики — ревьюеру, чья модель отличается от модели автора кода (объявляется DOWNGRADED, когда пул не может предложить другую). Скажите «не использовать команды» — и она мгновенно отойдёт в сторону.

Всего одна модель? Всё равно стоит — контролю уровня воды и доктрине всё равно, сколько у вас моделей.

## Встроенные навыки

- **db-query** — верификация MySQL/Redis только на чтение: выполните SQL, чтобы проверить записи, ключи кэша / TTL, согласованность между хранилищами. Отклоняет любую запись. Разовая настройка — ниже.
- **git-commit-message** — текст коммита по конвенции. Только текст; git не трогает.
- **requirement-docs** — единая спецификация для требований / PRD / дизайн-документов, архивируется в `docs/requirements-and-design/`.

## Быстрый старт

1. **Установите** — из любой сессии агента или через веб-менеджер плагинов:

   ```
   plugin_manager: install_bundle  target=dsh-switchman
   ```

   или из локального checkout'а (в режиме link; после подтягивания изменений снова выполните `remove_bundle` + `install_bundle`):

   ```
   plugin_manager: install_bundle  target=/path/to/dsh-switchman
   ```

   или из терминала через `dsh` CLI — выберите профиль в зависимости от того, как вы запускаете DSH:

   ```bash
   dsh plugin --profile web add dsh-switchman      # Web GUI
   dsh plugin --profile desktop add dsh-switchman   # десктоп-приложение
   ```

2. **Перезапустите DSH** — полностью закройте приложение и откройте заново (перезагрузки страницы недостаточно), чтобы таблица клиентских модулей подхватила бандл.

3. **Откройте страницу настроек** — Settings → dsh-switchman. Первый экран — языковые предпочтения: выпадающий список области действия — весь профиль или по проектам (`.switchman/lang.json` каждого проекта) — плюс по выпадающему списку на ответы / комментарии / документы, у каждого живая строка `current: …`. Можете пропустить — спросят один раз и запомнят (спросят на языке интерфейса DSH).

   ![Страница настроек и языковые предпочтения](docs/assets/conf-demo1.png)

4. **Заполните шесть пулов** — каждая карточка пула перечисляет кандидатов, сгруппированных по провайдеру; отметьте нужные. Отметьте **manual order**, и карточка станет нумерованным списком приоритетов с кнопками ↑ ↓ ×. Выпадающий список effort рядом с каждым выбранным маршрутом по умолчанию стоит на *follow lane*; если его зафиксировать, он покажет уровни, которые эта модель реально поддерживает (Low / High / Max…). Строка сводки в реальном времени показывает прогресс: «6/6 пулов задано · 3 в рейтинге · режим advice». Выбранные маршруты, которые ваши настройки DSH не авторизовали для явного выбора субагента, несут значок ⚠ с подсказкой — авторизуйте их также в настройках DSH (Subagents → model selection), иначе агенты, явно называющие их, будут отклонены и перейдут к неявной диспетчеризации.

   ![Пулы диспетчеризации](docs/assets/conf-demo2.png)

5. **Рейтинг и watermark** — порядок в таблице рейтинга — это порядок по возможностям (сильнейшие первыми), с опциональными tier-ами S/A/B/C; режим исполнения — `off` / advice / enforce (enforce = модели вне пула отклоняются). Ниже секция watermark ужесточает поведение по мере расхода токенов: три порога, бюджет чтения на вызов, поведение жёсткого режима (cap / deny), переключатель автоматической передачи управления и отдельный лимит для субагентов. Нижняя строка несёт команды: `/ctx-pause` — прекратить вмешательство · `/ctx-resume` — возобновить · `/ctx-handover` — сделать бэкап и передать управление прямо сейчас (он подводит сессию к границе простоя и ждёт окно повторной попытки компакции, поэтому результат может занять несколько минут).

   ![Рейтинг и watermark контекста](docs/assets/conf-demo3.png)

6. **Проверьте** — значок ⚡ появляется рядом с чипом пресета в шапке любой сессии; спросите у модели «что написано в последней секции твоего системного промпта?» — она должна упомянуть доктрину dsh-switchman.

**Разовая настройка db-query** (зависимости скриптов живут внутри каталога навыка):

```bash
bash <install-dir>/skills/db-query/scripts/setup.sh
```

## Как это работает

- Host-половина (`index.js` + `host/`) внедряет три динамические секции системного промпта, шлюзы бюджета чтения и enforce, автоматический захват ответов и три слэш-команды. Все настройки — volatile-поля: сохранённые изменения вступают в силу при следующей сборке промпта, без перезапуска.
- Client-половина (`client.js`) отрисовывает значок ⚡ рядом с чипом пресета и страницу настроек — через официальные сервисы settings-form.
- В боковой панели домашней страницы появляется отдельный пункт **Switchman** рядом со строкой Skills Center; один клик открывает ту же страницу настроек (языки, пулы и рейтинг, watermark) в виде центральной панели. Секция настроек и значок ⚡ остаются на месте.
- `cordis.patch.yml` дословно повторяет список плагинов каждого штатного пресета и расширяет только суффикс персоны; сами инструменты Agent Teams по-прежнему приходят из штатного `@deepseek-ai/dsh-experimental-agent-team-profile`.

## Обслуживание

- После обновления DSH, меняющего списки плагинов штатных пресетов, пересинхронизируйте `cordis.patch.yml` из новых `presets/*.patch.yml` (сохраните суффикс доктрины) и переустановите.
- Строки протокола, адресованные модели (`[SWITCHMAN:LANG|POOLS|WATERMARK]`), намеренно на английском и стабильны побайтово — не локализуйте их.
- `npm pack --dry-run` должен оставаться в аудитированной форме: 34 файла / ~111 kB (скриншоты из `docs/` в пакет никогда не попадают).
